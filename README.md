# 个人记账本（Personal Ledger）

单文件 HTML 复式记账应用，无需服务器、无需数据库，浏览器打开即用，支持 PWA 安装与离线使用。

## 功能
- 复式记账：收入 / 支出分类
- 股票投资：FIFO 成本核算
- 花呗跨期与退款处理
- 借贷自动平衡校验
- 数据导出 / 导入（JSON）

## 使用
- **在线**：访问 GitHub Pages 即用
- **本地**：下载 `个人记账本.html` 双击打开（file:// 下 Service Worker 不生效，不影响记账功能）
- **手机 App**：见 Release 中的 APK
